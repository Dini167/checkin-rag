# יומן בעיות ושיפורים

כל רשומה: בעיה ← אבחון ← תיקון ← תוצאה לפני ואחרי.
המדידות מגיעות מ־`python -m eval.run_eval` (קבצים ב־`eval/results/`).

---

## 1. סגנונות הכותרות לא מזוהים בקריאת קבצי Word
- **בעיה:** בניסיון הראשון לקרוא את המסמכים, python-docx החזיר `None` כסגנון של כל
  הכותרות, ולכן החלוקה לפי סעיפים לא הייתה עובדת.
- **אבחון:** בקבצים יש הפניה לסגנונות `Heading1` ו־`Heading2`, אבל הסגנונות עצמם לא
  מוגדרים בטבלת הסגנונות של הקובץ. python-docx מחפש את הסגנון בטבלה, לא מוצא, ומחזיר `None`.
- **תיקון:** קריאה ישירה של מזהה הסגנון מהפסקה (`read_paragraph_style_id` ב־`ingestion/docx_reader.py`).
- **תוצאה:** לפני: 0 סעיפים מזוהים. אחרי: 19 כותרות מסמך ו־112 כותרות סעיף.

## 2. BM25 של LlamaIndex לא מתאים לעברית
- **בעיה:** `BM25Retriever` של LlamaIndex מקבל רק stemmer (ברירת המחדל: אנגלית) וביטוי
  רגולרי, ולא אפשר לחבר אליו את ה־tokenizer העברי (README סעיף 13).
- **אבחון:** בדיקת החתימה של `BM25Retriever.__init__` בגרסה 0.8.0.
- **תיקון:** שימוש ישיר בספריית bm25s (שעליה הוא בנוי), שמקבלת רשימות מילים שפורקו מראש
  (`rag/bm25_index.py`).
- **תוצאה:** ממתין למדידה: Recall@5 בלי הורדת קידומות לעומת עם הורדת קידומות.

## 3. הורדת קידומות עיוורת משבשת מילים
- **בעיה:** "בקשה" הופכת ל"קשה", "בלבד" ל"לבד".
- **אבחון:** דוח `docs/prefix_report.md` (454 מילים שמהן תוסר קידומת).
- **תיקון:** הורדה רק כשהמילה שנשארת קיימת במסמכים, ורשימת חריגים ידנית.
- **תוצאה:** ממתין לבדיקת הדוח ולמדידה.

## 4. החיבור ל־Gemini נכשל בשגיאת תעודת SSL
- **בעיה:** כל קריאה ל־Gemini נכשלה עם `CERTIFICATE_VERIFY_FAILED: CA cert does not include key usage extension`.
- **אבחון:** ברשת מותקן סינון NetFree, שבודק תעבורה מוצפנת בעזרת תעודה משלו. התעודה מותקנת
  ב־Windows (ולכן הדפדפן עובד), אבל Python 3.13 בודק תעודות בצורה מחמירה ודוחה אותה.
- **תיקון:** הספרייה `truststore` גורמת ל־Python לאמת תעודות דרך מאגר התעודות של Windows (`config.py`).
- **תוצאה:** לפני: אף קריאה לא עוברת. אחרי: embedding ותשובות עובדים.

## 5. מודל התשובה החדש ביותר לא עונה בזמן
- **בעיה:** `gemini-3.8-flash` החזיר 504 (DEADLINE_EXCEEDED) אחרי 44 שניות, והדרישה היא תשובה תוך שניות.
- **אבחון:** השוואה בין המודלים על אותה שאלה: 3.5-flash-lite ענה תוך 1.4 שניות, 3.6-flash תוך 3.9
  שניות, ו־3.8-flash נכשל.
- **תיקון:** מודל התשובה הוחלף ל־`gemini-3.6-flash`. ניתוח השאלה נשאר ב־3.5-flash-lite המהיר.
- **תוצאה:** תשובה תוך כ־4 שניות במקום כישלון.
